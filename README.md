# Optimizer-Wasm

このプロジェクトは、Rustを使用して最適化問題のWebAssemblyアプリケーションを作成します。
JavaScriptから呼び出すことにより高速に最適化問題を解くことを目的とします。

## プロジェクト構成

- `src/lib.rs`: Rustで書かれたWebAssembly（Wasm）モジュールのエントリーポイントです。このファイルでは、最適化問題を解決するための関数を定義し、JavaScriptから呼び出せるようにしています。

## はじめに

このプロジェクトをビルドして実行するには、Rustと必要なWebAssemblyツールがインストールされていることを確認してください。以下の手順に従ってください。

1. リポジトリをクローンするか、プロジェクトファイルをダウンロードします。
   ```
   git clone git@github.com:tagawa0525/prac_wasm.git
   ```
2. プロジェクトディレクトリに移動します:
   ```
   cd prac_wasm
   ```
3. プロジェクトをビルドします:
   ```
   cargo install wasm-pack
   wasm-pack build --target web
   ```
4. HTTPサーバーを立ち上げ、ブラウザから`localhost:8000`にアクセスします。
   ```
   python -m http.server
   ```
4. もしくは、直下のJavascriptを実行します。
   ```
   deno  --allow-read .\optimizer-wasm.js
   ```

## `src/lib.rs`の説明

`src/lib.rs`ファイルは、Rustで書かれたWebAssembly（Wasm）モジュールのエントリーポイントです。このファイルでは、最適化問題を解決するための関数を定義し、JavaScriptから呼び出せるようにしています。

### 主な内容

1. **依存関係のインポート**:
 - `serde`: Rustのデータ構造をシリアライズおよびデシリアライズするためのクレート。
 - `serde_wasm_bindgen`: `serde`と`wasm_bindgen`の間でデータを変換するためのクレート。
 - `wasm_bindgen`: RustとJavaScriptの間で相互運用性を提供するためのクレート。

2. **モジュールの宣言**:
 - `algorithms`モジュールを公開します。このモジュールには、最適化アルゴリズムが含まれています。

3. **データ構造の定義**:
 - `Store`構造体を定義します。この構造体は、店舗の情報を保持します。

4. **Wasm関数の定義**:
 - `solve_optimization_problem`関数を定義します。この関数は、JavaScriptから呼び出され、最適化問題を解決します。
 - 引数として、価格、在庫、必要な商品数、店舗情報を受け取ります。
 - 受け取ったデータをRustのデータ構造に変換し、`algorithms::genetic::optimize`関数を呼び出して最適化を行います。
 - 最適化の結果をJavaScriptに返します。

## `src/tests`の説明

`src/tests`ディレクトリには、プロジェクトのテストコードが含まれています。このディレクトリには、最適化アルゴリズムの動作を検証するためのテストが含まれています。

### 主な内容

1. **テストモジュールの定義**:
 - 各テストファイルは、特定のアルゴリズムや機能を検証するためのテストケースを含んでいます。

2. **テストケースの実装**:
 - 各テストケースは、特定の入力データに対して期待される出力を検証します。
 - テストケースは、Rustの標準的なテストフレームワークを使用して実装されています。
