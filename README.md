# Optimizer-Wasm

このプロジェクトは、Rustを使用して最適化問題のWebAssemblyアプリケーションを作成します。
JavaScriptから呼び出すことにより高速に最適化問題を解くことを目的とします。

## プロジェクト構成

- `src/lib.rs`: 他のRustプロジェクトやメインアプリケーションで利用できる関数、型、モジュールなどのライブラリコードが含まれています。
- `src/main.rs`: アプリケーションのエントリーポイントで、現在はコンソールに「Hello, world!」と表示します。
- `Cargo.toml`: Rustプロジェクトの設定ファイルで、パッケージ名、バージョン、著者、依存関係、その他の必要なメタデータを指定します。

## はじめに

このプロジェクトをビルドして実行するには、Rustと必要なWebAssemblyツールがインストールされていることを確認してください。以下の手順に従ってください。

1. リポジトリをクローンするか、プロジェクトファイルをダウンロードします。
```
   git clone git@github.com:tagawa0525/prac_wasm.git
```
2. プロジェクトディレクトリに移動します:
   ```
   cd prac_wasm
   ```
3. プロジェクトをビルドします:
   ```
   wasm-pack build --target web
   ```
4. HTTPサーバーを立ち上げます:
   ```
   python -m http.server
   ```
